# 3차 검증: 제22대 출결 공개자료

검증일: 2026-10-01 · 실제 의원 등급은 산출하지 않음

## 1. 범위

열린국회정보의 파일데이터 목록을 조회해 제22대 임기 시작 이후부터 공개된 파일을 검사했다.

| 구분 | 파일 | 기간 | 형식 |
| --- | ---: | --- | --- |
| 본회의 | 23개 | 제415회~제438회 | XLSX |
| 상임위원회 | 26개 | 2024-06~2026-08, 공개된 월 | PDF |
| 특별위원회 | 24개 | 2024-07~2026-08, 공개된 월 | PDF |
| 합계 | 73개 |  |  |

제425회는 국회회의록에 '본회의는 개의되지 않았음'으로 표시되며, 출결 파일 목록에도 없다. 제439회는 검증일 현재 진행 중이고 출결 파일이 아직 공개되지 않았다. 따라서 본회의 23개 파일은 종료·공개된 제22대 회기의 목록과 일치한다.

파일 목록은 새 파일이 추가되거나 정정본으로 교체될 수 있다. 수집 시각·파일 식별자·해시를 보존해야 한다.

## 2. 본회의 출결

### 구조 검사

- 23개 XLSX, 23개 시트
- 회의일 119일
- 의원-회기 행 6,857개
- 의원-회의일 상태 셀 35,511개
- 이 중 공식 상태 35,502개, 해당 회의의 평가 대상이 아님을 나타내는 `-` 9개
- 상태별 합계: 출석 32,425, 결석 1,548, 청가 1,076, 출장 440, 결석신고서 13
- 인식한 상태: 출석·결석·청가·출장·결석신고서
- 회기별 상태 셀과 회기별 합계 불일치: 0행
- 미인식 상태·공란: 0셀
- 제22대 재임 이력을 적용한 의원 식별 미해결: 0행

국회회의록의 제415~438회 본회의 목록도 대조했다. 출결 파일의 119개 회의일은 회의록의 같은 기간 119개 회의일과 일치했다. 제425회는 본회의가 개의되지 않았다.

파일마다 의원 행 수가 286~301명으로 다르다. 재임자 변동 및 회기 안의 시점 차이가 있으므로, 파일 행 수를 현재 의원 수 299로 강제하지 않는다. 실제 평가에서는 각 행에 기록된 회의일 상태를 사용하고 재임 기간과 대조한다.

### 원자료 누적 합계 오류 1건

제436회 파일의 김미애 행:

- 회기 내 4일은 모두 출석이고 회기 합계도 `4/4`로 일치.
- 누적 표시는 회의일수 114, 출석 96, 결석 14, 청가 1, 출장 0, 결석신고서 0.
- 상태 합은 111로 누적 회의일수 114와 3 차이.

누적값 자체를 평가에 사용하지 않고, **각 회기 파일의 일별 상태를 한 번씩 합산**한다. 이전 파일의 누적 열을 더하면 중복 집계된다. 김미애 건은 제435회까지의 누적과 다음 회기 누적을 함께 대조하고 원자료 오류 여부를 확인한 뒤 확정한다.

전후 파일을 대조하면 제435회 누적은 `110 = 92+14+1+3+0`, 제436회 일별 출석은 4회, 제437회 누적은 `117 = 99+14+1+3+0`이다. 따라서 제436회 누적 열에서 출장 3이 0으로 빠진 것으로 추정된다. 평가 계산은 누적 열을 사용하지 않으므로 일별 4회 출석에는 영향이 없다.

## 3. 위원회 출결

### 구조 검사

- PDF 50개: 상임위 26개, 특위 24개
- 총 428페이지, 텍스트 없는 페이지 0
- 이름·일별 상태·6개 합계 형식에 맞는 행 9,285개
- 위 패턴의 후보 행 9,285개가 모두 파싱됨
- 한글명·한자명·제22대 재임 이력을 사용해 9,285행 모두 의원코드에 연결됨(고유 320명)
- 일별 상태 23,836개: 출석 20,984, 결석 1,429, 청가 1,086, 출장 295, 결석신고서 42
- 일별 상태 수와 공개 합계 불일치: 4행

이 수치는 PDF의 형식·신원 연결 검증 결과다. 위원회 회의별 전체 대상 인원이 빠짐없이 실렸는지와 각 일별 상태가 올바른 위원회 회의일에 연결됐다는 뜻은 아니다.

### 원자료 합계 불일치 4건

| 파일 | 의원 | 일별 상태에서 센 값 | 파일 합계 |
| --- | --- | --- | --- |
| 2026-07 법제사법위원회 | 윤상현 | 출석 4, 결석 3 | 출석 3, 결석 4 |
| 2025-07 국방위원회 | 윤상현 | 출석 1, 청가 1 | 출석 1, 결석 1 |
| 2025-02 비상계엄 국정조사특위 | 곽규택 | 출석 5, 출장 1 | 출석 5, 청가 1 |
| 2024-10 외교통일위원회 | 이재명 | 출석 2 | 출석 1, 청가 1 |

PDF 텍스트 추출 행뿐 아니라 표시된 일별 상태와 합계가 서로 달라 자동 합계 오류로 분류했다. 어느 값이 실제 출결인지 다른 공식 원문으로 재확인하기 전에는 해당 행을 점수에 반영하지 않는다.

### 공개 목록의 빈 월

- 상임위: 2026-06 파일 없음
- 특위: 2024-06, 2025-10 파일 없음

파일이 없다는 사실만으로 회의 누락이라고 단정할 수 없다. 해당 월에 평가 대상 회의가 없었는지 회의록·위원회 일정과 대조해야 한다. 월별 PDF에서 위원회 이름이 빠진 경우도 그 달 회의가 없었는지 확인하기 전까지 0회로 단정하지 않는다.

위원회별 일정 API(`nrsldhjpaemrmolla`)의 조회 당시 1,870개 일정도 확인했다. 빈 월에는 일정이 존재했다.

- 2024-06: 전체회의 29개 포함 32개 일정. 상임위 PDF만 있고 특위 PDF 없음.
- 2025-10: 전체회의 51개 포함 52개 일정. 상임위 PDF만 있고 특위 PDF 없음.
- 2026-06: 전체회의 8개 일정. 특위 PDF만 있고 상임위 PDF 없음.

세 월을 상세 분류하면 다음과 같다.

- 2024-06의 일정은 상임위원회 10곳의 전체회의 29개와 소위원회 2개 등으로, 특위 출결 파일이 없는 사실과 충돌하지 않는다.
- 2025-10의 52개 일정은 모두 이름상 상임위원회이며 특위 출결 파일이 없는 사실과 충돌하지 않는다.
- 2026-06의 8개 일정은 모두 제목상 인사청문특위·국정조사특위·기후위기특위 회의다. 따라서 상임위 출결 파일이 없는 사실과 충돌하지 않는다.

일정 API는 일부 특위를 소관 상임위 이름으로 표시하므로 `COMMITTEE_NAME`만으로 구분하지 않고 `TITLE`을 함께 사용했다. 이 비교 범위에서는 **목록의 빈 월이 출결 대상 회의 누락이라는 증거는 발견하지 못했다.** 다만 개별 위원회가 파일에서 빠졌는지는 전체 회의일 구조화 후 다시 검증한다.

## 4. 출석 지표 산정 원칙

아래는 데이터 검증 결과에서 도출한 제안이며, 평가 산식 최종 확정 전이다.

1. 본회의 출석률은 공개된 회의일별 상태를 분모·분자로 사용한다.
2. 위원회 출석률은 의원이 해당 위원회에 재임한 기간과 그 위원회의 실제 회의일을 교차한다.
3. 상임위와 특위는 역할·회의 빈도가 달라 하나의 분모로 바로 합치지 않는다.
4. 출석·출장·청가·결석신고서의 점수 처리 규칙은 별도로 공개한다. 공식 분류를 보존한다.
5. 일별 상태와 합계가 다르면 계산 결과를 추측하지 않고 검토 상태로 둔다.
6. 정정 파일은 원본을 덮어쓰지 않고 버전과 적용일을 보존하며 최신 정정본을 사용한다.
7. 본회의 누적 열은 검산용으로만 사용하고 일별 상태에서 다시 계산한다.

## 5. 평가 준비 상태

본회의 출결은 일별 상태와 신원 연결이 가능해 평가 지표로 사용할 수 있는 수준에 가까워졌다. 위원회 출결은 PDF의 기계 판독 가능성은 확인했으나, 다음 검증이 남았다.

- 위원회별 표 구획·날짜 열의 완전한 구조화
- 의원별 위원회 재임 기간과 각 행·위원회·회의일 연결
- 월별 PDF의 위원회별 회의일과 회의록 전체 목록 대조
- 불일치 4행의 다른 공식 기록 대조
- 현재 목록에 없는 정정본 탐지 방식

따라서 50/30/20 평가안의 출석 20%를 곧바로 확정하지 않는다. 본회의 출석은 먼저 계산할 수 있지만, 위원회 출석과 동등하게 합산할 근거가 필요하다.

## 6. 재현 정보

- Node.js 22에서 XLSX는 SheetJS, PDF는 PDF.js로 읽었다. 제품 기술 스택 결정은 아니다.
- 파일 다운로드 오류 0건.
- PDF 50개 모두 텍스트가 있었고 OCR은 사용하지 않았다.
- [요약 증거 JSON](attendance-audit-evidence-2026-10-01.json)과 [파일별 검사 CSV](attendance-audit-files-2026-10-01.csv)를 저장한다.
- CSV의 SHA-256은 내려받은 공식 파일 바이트 기준이다. `arithmetic_mismatches`는 회기별 일별 합계 및 누적 합계 오류를 합친 수다.
- 공식 목록: [본회의 출결](https://open.assembly.go.kr/portal/data/service/selectServicePage.do/O4Q5B50011905O18367), [위원회 출결](https://open.assembly.go.kr/portal/data/service/selectServicePage.do/OND4F9001191DA18437)
- API 키·개별 연락처·원본 XLSX/PDF는 리포지토리에 저장하지 않았다.
