# 단계별 진행 계획

기준일: 2026-10-01

기획을 먼저 확정하고 단계적으로 진행한다. 리포지토리 연결은 전체 개발 착수를 의미하지 않는다. 각 단계의 산출물과 남은 쟁점을 기록하고, 완료된 작업을 검토한 뒤 커밋·푸시한다.

| 단계 | 산출물 | 완료 기준 | 현재 상태 |
| --- | --- | --- | --- |
| 0. 초기 기획 | 서비스 범위·등급안·결정 기록 | 확정 사항과 미정 사항을 문서화 | 문서화 완료 |
| 1. 데이터 검증 | 서비스·필드 목록, 원문 대조 결과, 누락 보고 | 핵심 지표의 계산 가능 여부 확인 | 본회의·표결 예외 규칙 확정, 위원회 회의일 구조화 진행 중 |
| 2. 평가 기준 확정 | 산식 명세, 적격 기준, 동점·결측 처리, 민감도 검토 | 실제 분포 검토 및 기준 합의 | 1단계 산식(입법 40·표결 35·출석 25) 확정, 위원회 출석 보류 |
| 3. 수집·집계 구현 | 데이터 수집, 갱신, 재현 가능한 집계 | 원문 대조·집계 검증 통과 | 대기 |
| 4. 화면 구현 | 전체 실적표·의원 상세·2인 비교 | 등급에서 원문까지 추적, 검색·정렬·비교 확인 | 대기 |
| 5. 공개 준비 | 배포, 갱신 상태, 산식·출처 안내, 정정 운영 | 데이터와 화면 기준일 일치, 운영 점검 완료 | 대기 |

## 바로 다음에 할 일

[1단계 평가 산식](evaluation-draft.md)을 확정했으므로 다음을 진행한다.

- 출결 원자료 불일치 5행의 회의록·위원회 원문 대조 및 예외 처리
- 위원회 출결 9,285행의 표 구획·회의일·위원회 재임 연결 → 2단계 산식에 위원회 출석 반영
- 표결 예외 77건 처리 규칙의 전체 데이터셋 회귀 검증
- 180일 미만 재임 21명의 "관찰 기간 부족" 표시 로직 설계
- 백분위·동점 처리 알고리즘을 코드로 구현하고 299명 전수에 재현 테스트
- 재표결 이벤트 및 평가 대상 의안 종류의 포함 기준 확정

평가 비중은 1단계까지 확정했으나, 실제 의원 등급은 위 항목이 끝나기 전에 산출하거나 공개하지 않는다.
