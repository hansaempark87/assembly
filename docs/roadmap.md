# 단계별 진행 계획

기준일: 2026-10-01

기획을 먼저 확정하고 단계적으로 진행한다. 리포지토리 연결은 전체 개발 착수를 의미하지 않는다. 각 단계의 산출물과 남은 쟁점을 기록하고, 완료된 작업을 검토한 뒤 커밋·푸시한다.

| 단계 | 산출물 | 완료 기준 | 현재 상태 |
| --- | --- | --- | --- |
| 0. 초기 기획 | 서비스 범위·등급안·결정 기록 | 확정 사항과 미정 사항을 문서화 | 문서화 완료 |
| 1. 데이터 검증 | 서비스·필드 목록, 원문 대조 결과, 누락 보고 | 핵심 지표의 계산 가능 여부 확인 | 1차 가용성·표본 검증 완료, 전체 품질 검증 진행 중 |
| 2. 평가 기준 확정 | 산식 명세, 적격 기준, 동점·결측 처리, 민감도 검토 | 실제 분포 검토 및 기준 합의 | 대기 |
| 3. 수집·집계 구현 | 데이터 수집, 갱신, 재현 가능한 집계 | 원문 대조·집계 검증 통과 | 대기 |
| 4. 화면 구현 | 전체 실적표·의원 상세·2인 비교 | 등급에서 원문까지 추적, 검색·정렬·비교 확인 | 대기 |
| 5. 공개 준비 | 배포, 갱신 상태, 산식·출처 안내, 정정 운영 | 데이터와 화면 기준일 일치, 운영 점검 완료 | 대기 |

## 바로 다음에 할 일

[1차 검증 결과](data-validation-2026-10-01.md)를 바탕으로 다음을 진행한다.

- 표결 전체 기간에서 개인 합계와 총계의 불일치 범위를 확인하고 국회 원문 보완 방식 검증
- 제22대 전체 재임자 식별자·이력과 동명이인 연결 검증
- 본회의·상임위·특위 출결의 전체 기간과 정정 파일·빈칸 처리 검증
- 공동대표발의·대안 관계 처리 및 공통 평가 기준일 제안

평가 비중과 실제 등급은 데이터 검증 전에 확정하거나 산출하지 않는다.
