# 단계별 진행 계획

기준일: 2026-10-01

기획을 먼저 확정하고 단계적으로 진행한다. 리포지토리 연결은 전체 개발 착수를 의미하지 않는다. 각 단계의 산출물과 남은 쟁점을 기록하고, 완료된 작업을 검토한 뒤 커밋·푸시한다.

| 단계 | 산출물 | 완료 기준 | 현재 상태 |
| --- | --- | --- | --- |
| 0. 초기 기획 | 서비스 범위·등급안·결정 기록 | 확정 사항과 미정 사항을 문서화 | 문서화 완료 |
| 1. 데이터 검증 | 서비스·필드 목록, 원문 대조 결과, 누락 보고 | 핵심 지표의 계산 가능 여부 확인 | 본회의·표결 예외 규칙 확정, 위원회 회의일 구조화 진행 중 |
| 2. 평가 기준 확정 | 산식 명세, 적격 기준, 동점·결측 처리, 민감도 검토 | 실제 분포 검토 및 기준 합의 | 1단계 산식(입법 40·표결 35·출석 25) 확정, 위원회 출석 보류 |
| 3. 수집·집계 구현 | 데이터 수집, 갱신, 재현 가능한 집계 | 원문 대조·집계 검증 통과 | D1 스키마·시드·1단계 점수 계산 완료(299명), 정기 갱신 자동화는 대기 |
| 4. 화면 구현 | 전체 실적표·의원 상세·2인 비교 | 등급에서 원문까지 추적, 검색·정렬·비교 확인 | 전체 실적표·의원 상세 배포 완료, 2인 비교 화면 대기 |
| 5. 공개 준비 | 배포, 갱신 상태, 산식·출처 안내, 정정 운영 | 데이터와 화면 기준일 일치, 운영 점검 완료 | Cloudflare Pages 배포 완료(assembly-dashboard.pages.dev), 정식 공개 전 검토 대기 |

## 바로 다음에 할 일

[Cloudflare Pages 1차 배포](../README.md#개발-환경)를 완료했으므로 다음을 진행한다.

- 위원회 출결 9,285행의 표 구획·회의일·위원회 재임 연결 → 2단계 산식에 위원회 출석 반영
- 출결 원자료 불일치 5행의 회의록·위원회 원문 대조 및 예외 처리
- 표결 예외 77건 처리 규칙의 전체 데이터셋 회귀 검증
- 의원 간 2인 비교 화면 구현
- 정기 데이터 갱신 자동화(국회 API → D1 재적재 → 점수 재계산) 설계
- 정식 공개 전 등급 공개 승인 검토(`gradeDatasetApproved` 플래그 전환 기준 수립)

평가 비중은 1단계까지 확정하고 화면도 배포했으나, 현재 공개된 등급은 검증용이며 정식 공개 승인 전이다.
