# 의사결정 기록

## 2026-10-01 — 프로젝트 방향

- 목적: 검증 가능한 의정활동 실적을 공개하고 의원 간 경쟁을 유도해 일하는 국회를 만든다.
- 진행 방식: 개발보다 기획 우선, 단계별 진행.
- 에이전트가 기획을 주도하고 가능한 API 실무를 직접 처리한다.
- 첫 범위: 전체 의원 실적표, 의원 상세 성적표, 의원 간 비교.
- 시민 참여 평가·투표·평점 기능 제외. 이전 포함 제안은 폐기.
- 상대평가 종합등급과 항목별 등급 표시.
- 등급 기본안: S/A/B/C/D, 목표 분포 10/20/40/20/10. 동점은 동일 등급.
- 원문 근거, 실제 건수·비율, 평가 대상 인원, 기준일을 함께 표시.
- 리포지토리: https://github.com/hansaempark87/assembly
- 사용자가 문서와 이후 단계별 작업의 GitHub 저장·커밋·푸시를 요청함.
- 인증정보는 커밋하지 않음.

## 합의된 방향과 구분해야 할 초안

- 입법 성과 50%, 표결 참여 30%, 회의 출석 20%는 검증 전 제안이다.
- 대안반영폐기 인정 방식, 백분위 계산법, 등급 경계 동점 처리, 최소 재임 기간은 미확정이다.
- 출결 데이터 제공 여부와 완전성은 아직 미확인이다.
- 종합등급은 모든 핵심 검증과 산식 합의 이후 공개한다.
- 공식 데이터라고 해서 평가 비중까지 객관적 사실이 되는 것은 아니다.

## 2026-10-01 — 1차 실조회 발견 (사용자 추가 합의와 구분)

- API 목록 고유 280개, 현역 의원 고유 코드 299개 확인.
- 입법 상태별 원문 대조 3건 일치. 복수 대표발의자 사례 확인.
- 최신 표결 표본 3건에서 개인 API 참여 합계가 총계보다 각 12표 적음. 국회 웹페이지에서 API 미조회 의원의 찬성 기록을 확인.
- 본회의 XLSX와 위원회 PDF 출결 자료를 확보하고 표본 산술 검증 수행.
- 동명이인 및 현재 명단에 없는 과거 의원 기록이 있어 이름 단독 연결 금지.
- 전체 품질 검증 및 표결 누락 보완이 남아 1단계 전체를 완료로 표시하지 않음.
- 평가 비중이나 등급 경계는 이번 작업으로 변경·확정하지 않음.

- 총계는 맞지만 날짜 포함 재임 명부와 차이가 있는 338건도 발견해, 추가 원문 대상 총 814건 확인.

- API 자체 검사 1,033건과 원문 보완 검사 737건, 총 1,770건이 정해진 검증 조건 통과. 개인 등급 공개 승인과는 다름.

- 재임 경계일 76건 및 의안 2215128 총계 불일치 1건은 보류. 평가 비중은 계속 초안.

- 제22대 공개 본회의 출결 XLSX 23개, 상임위 PDF 26개, 특위 PDF 24개 검사.
- 본회의 119일, 의원-회의일 상태 35,511셀의 회기별 합계 일치 및 신원 연결 확인.
- 본회의 누적 합계 불일치 1행, 위원회 일별 상태와 합계 불일치 4행 발견. 임의 보정 없이 보류.

- 표결 보류 77건은 회의록 대조로 처리 방향을 정함. 76건은 경계일 의원을 분모에서 제외하고, 의안 2215128은 정정된 개인 명단 196/1을 우선하는 안을 회귀 검증할 예정.
- 상대평가 비중과 실제 등급은 계속 미확정.

## 출결·표결 후속 발견 — 2026-10-01

- 제415~438회 본회의 출결 119일이 국회회의록 119일과 일치함을 확인.
- 위원회 PDF 9,285행 모두 제22대 의원코드에 연결함.
- 빈 월 3곳을 일정 API로 대조한 결과 파일 종류와 회의 성격이 일치해 공개 누락 증거는 발견하지 못함.
- 재임 경계일 76건은 회의록 및 출결표를 근거로 해당 경계 의원을 분모에서 제외하는 처리안을 마련.
- 의안 2215128은 회의록의 정정 문구에 따라 개인 명단 196/1을 우선하고 총계 차이를 공개하는 처리안을 마련.
- 본회의 일별 출석은 지표 계산이 가능한 수준이나, 위원회 출석은 회의일·재임 연결 완료 전 종합점수에서 제외하는 단계적 방안을 권고.

## 1단계 평가 산식 확정 — 2026-10-01

- 법안 발의 목록 전체 19,730건을 페이지 전수(20쪽) API로 수집해 확인. 처리 결과가 난 건은 5,011건(25%)이며, 180일 이상 계류 법안도 66~70%가 여전히 계류 상태라 계류를 가결 실패로 보지 않는다는 원칙을 재확인함.
- 공동 대표발의(복수 `RST_MONA_CD`) 214건을 확인해 각 대표발의자에게 모두 건수를 귀속하는 방식으로 처리함.
- 299명 현직 의원 중 278명(93%)이 2024-05-30 임기 개시일부터 재임해 동일 조건 비교가 가능함을 확인. 나머지 21명은 재임 시작일이 흩어져 있어 재임일수 180일 미만은 종합순위에서 제외하기로 함.
- 위원회 출석을 제외한 입법 성과 40% · 표결 참여 35% · 본회의 출석 25%를 1단계 산식으로 확정함. 위원회 출석은 회의일·재임 연결이 끝나는 대로 2단계에서 별도 비중으로 추가함.
- 이 산식으로도 실제 의원 등급은 아직 산출·공개하지 않음(`gradeDatasetApproved: false`).

## 초기 안내 정정

- 무인증 API 조회만으로 전체 데이터 확보가 가능하다는 설명은 부정확했다. 관찰된 응답은 5건과 첫 페이지로 제한됐다.
- API 목록 280개 수집 시도는 동일 5개 반복으로, 전체 목록 수집 성공이 아니었다.
- 비슷한 법안을 같은 날 발의했다는 이유만으로 자동 병합하는 평가 방식은 채택하지 않는다.
- 선거기간에 랭킹을 일괄 중단해야 한다는 이전 설명은 법적 근거와 적용 조건을 확인하지 않은 단정이었다. 확정 운영 정책으로 채택하지 않는다.
