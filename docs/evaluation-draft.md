# 상대평가 설계 초안

기준일: 2026-10-01 · 상태: **방향 합의 / 산식 미확정 / 실제 의원 등급 미산출**

## 2026-10-01 실조회 반영

[1차 검증](data-validation-2026-10-01.md)에서 개인 표결 API 누락과 공식 XLSX/PDF 출결 자료를 확인했다. 50/30/20은 계속 초안으로 유지한다. 다음 사항을 산식 확정 전에 해결해야 한다.

- 개인 표결 합계와 공식 총계가 다른 안건의 보완 및 기록 완전성 확인
- 복수 대표발의자에 대한 점수 귀속 규칙
- 현재 명부와 과거 출결 명부 차이, 동명이인 연결
- 출결 자료 지연에 맞춘 공통 평가 기준일과 최신 활동 기준일의 구분

출결 자료 확보 자체는 가능하므로 자료가 없다는 이유로 출석 비중을 즉시 제거하지 않는다. 원문과의 대조를 통과한 자료만 평가에 투입한다.

[3차 출결 검증](attendance-audit-2026-10-01.md)에서 본회의 119일의 일별 상태를 확인했고 위원회 PDF 50개의 9,285행도 의원코드에 연결했다. 그러나 공개 합계와 다른 5행, 위원회별 회의일·재임 연결이 남아 있어 출석 20%는 계속 검증 전 초안이다. 출결은 누적 열이 아닌 일별 상태에서 재계산하고, 불일치 행을 임의 보정하지 않는다.

## 1. 합의한 표시 방식

추가 [2차 검증](vote-and-identity-audit-2026-10-01.md)에서 표결 총계와 명부를 함께 검사해야 함을 확인했다. 총계 일치만으로 평가 자료를 승인하지 않는다. 77건의 보류 안건을 임의 제외하거나 해당 의원의 분모만 줄이지 않으며, 경계일 자격과 원천 표결 차이를 먼저 확인한다. 재표결 단위와 대상 의안 종류도 확정 전이다.

종합등급과 항목별 등급, 순위, 상대적 위치, 실제 실적 수치를 함께 표시한다.

| 등급 | 목표 구간 |
| --- | --- |
| S | 상위 10% |
| A | 다음 20% (누적 30%까지) |
| B | 중간 40% (누적 70%까지) |
| C | 다음 20% (누적 90%까지) |
| D | 하위 10% |

동점은 같은 등급으로 처리한다. 따라서 구간별 실제 인원 비중은 달라질 수 있다. 동점 경계 처리 방식, 순위 방식, 소규모 비교 집단의 최소 크기는 데이터 검증 후 확정한다. 실적이 모두 같은 항목에 억지로 등급을 나누지 않는다.

## 2. 가중치 제안 — 확정 산식 아님

| 평가 축 | 제안 비중 | 기초 지표 및 남은 검증 |
| --- | ---: | --- |
| 입법 성과 | 50% | 대표발의 법안 가결·대안 반영 기록. 각각의 인정 범위와 내부 가중치 미정 |
| 표결 참여 | 30% | 참여 가능한 본회의 기록표결 중 참여 비율. 대상·참여 코드 정의 검증 필요 |
| 회의 출석 | 20% | 본회의·소속 위원회 출석률. 자료 확보 및 두 출석률의 합산 방식 미정 |

제안 절차는 `원자료 집계 → 항목별 백분위 변환 → 가중합 → 종합 순위 → 상대등급`이다. 백분위 계산법과 동점 처리까지 명세한 뒤 구현한다.

공식 원자료는 사실이지만, 지표 선정·가중치·등급 경계는 설계자의 판단이다. 이를 공개하며 '완전히 객관적인 능력 평가'로 표현하지 않는다.

## 3. 지표별 해석 원칙

### 입법

- 대표발의와 공동발의를 분리한다. 공동발의 건수는 보조 정보다.
- 단순 발의량 자체를 종합평가의 직접 가점으로 사용하지 않는다.
- 원안가결·수정가결·대안반영폐기를 별도로 집계한다.
- 대안반영폐기를 단순 실패로 처리하지 않으며, 해당 의원의 제안이 전부 반영됐다고도 간주하지 않는다.
- 위원회 대안과 원안 관계를 확인해 중복 귀속·중복 점수를 검토한다.
- 비슷한 제목이나 같은 날 발의됐다는 이유만으로 법안을 임의 병합하지 않는다.
- 가결률은 분자·분모와 관찰 기간을 정의하기 전 평가에 반영하지 않는다. 신규 발의와 계류 법안에는 결과 관찰 시간이 짧다는 문제가 있다.

### 표결·출석

- 의안 전체 찬반 집계로 개인 참여율을 계산하지 않는다. 개인별 표결 기록이 필요하다.
- 참여율의 분모는 해당 의원 재임 중 참여 대상이었던 공개 기록표결로 정의하고 예외를 검증한다.
- 찬성·반대·기권 등 응답 코드의 의미를 확인해 참여 여부를 정의한다. 찬반 입장 자체는 가감점하지 않는다.
- 무기명 표결 등 개인 기록을 확인할 수 없는 표결은 범위를 명시한다.
- 표결 불참과 회의 결석은 다른 기록이다.
- 위원회 출석 분모는 해당 기간의 위원회 소속 이력을 반영해야 한다.
- 청가·출장 등 공식 출결 분류가 있을 경우 원래 분류를 보존하고 처리 기준을 공개한다.

## 4. 공정한 비교 및 결측 처리

- 기본 비교는 동일한 평가 기간과 적격 기준을 적용한 전국 집단이다.
- 임기 누적 기록을 기본으로, 월간 활동과 월말 등급 이력을 구분한다.
- 재임 기간이 짧은 의원의 최소 관찰 기간·평가 유보 기준을 사전에 정한다. 단순 연환산은 검증 없이 적용하지 않는다.
- 자료 누락을 실적 0으로 바꾸지 않는다. 분모가 0이면 비율 미산출로 표시한다.
- 비교 대상에 필요한 데이터가 확보되지 않으면 평가를 유보하거나 전체 산정안을 재검토한다. 의원마다 가중치를 임의 재분배하지 않는다.
- 높은 상대등급이 높은 절대 실적을 뜻하지 않을 수 있으므로 원래 수치를 항상 표시한다.
- 순위 변화는 본인 활동, 비교 집단 변화, 원천 정정, 산식 개정 중 무엇에 기인하는지 구분한다.

## 5. 공개 전 검증 항목

1. 출결 자료와 의원별 표결 기록의 제공 범위·누락률 확인
2. 의원·법안 식별자 연결 및 중복 제거 검증
3. 입법 성과 인정 방식과 원안·대안 관계 확인
4. 평가 기간·재임 이력·최소 관찰 기간 확정
5. 백분위·동점·등급 경계·분모 0·결측 처리 명세
6. 비중 변화에 따른 등급 변동과 특정 지표의 과도한 영향 검토
7. 원문과 표본 수치 대조 및 오류 정정 절차 마련
8. 산식 버전과 적용일 기록 후 최종 기획 합의

이 항목들이 완료되기 전 50/30/20을 확정 산식으로 발표하거나 실제 의원을 S~D로 평가하지 않는다.
