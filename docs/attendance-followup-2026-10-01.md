# 4차 검증: 출결 전 기간 및 표결 예외 후속

검증일: 2026-10-01 · 실제 의원 등급은 산출하지 않음

## 1. 본회의 출결 전체 기간

제22대 임기 중 공개된 제415회~제438회 본회의 출결 XLSX 23개를 모두 검사했다. 제425회는 국회회의록에 본회의가 개의되지 않았다고 표시된다. 제439회는 검증일 현재 진행 중이며 출결 파일이 아직 공개되지 않았다.

| 검사 | 결과 |
| --- | ---: |
| 공개 XLSX | 23개 |
| 회의일 | 119일 |
| 의원-회기 행 | 6,857개 |
| 의원-회의일 셀 | 35,511개 |
| 공식 출결 상태 | 35,502개 |
| 평가 대상 아님(`-`) | 9개 |
| 의원코드 연결 미해결 | 0행 |
| 회기별 일별 상태와 합계 불일치 | 0행 |

상태별 기록은 출석 32,425, 결석 1,548, 청가 1,076, 출장 440, 결석신고서 13이다. 이는 의원 전체를 합한 기록 수이며 개인 평가 결과가 아니다.

국회회의록 제415~438회에서 확인한 본회의 날짜도 119개였고, XLSX의 날짜 집합과 일치했다. 따라서 **2026-08-26까지 종료·공개된 본회의 출결의 날짜 범위는 완전한 것으로 판단한다.**

### 누적값 오류 처리

제436회 김미애 의원 행의 누적값은 `회의일수 114`, 상태 합계는 `111`이다. 전후 파일을 함께 보면 제435회의 출장 3회가 제436회 누적 열에서 빠졌다가 제437회에 다시 나타난 것으로 추정된다.

- 회기별 일별 상태와 회기 합계는 정상이다.
- 누적 열은 평가에 사용하지 않는다.
- 23개 파일의 일별 상태를 중복 없이 다시 계산한다.

## 2. 위원회 출결 전체 공개 파일

2024-06~2026-08 공개 목록에서 PDF 50개를 검사했다.

| 구분 | 결과 |
| --- | ---: |
| 상임위원회 파일 | 26개 |
| 특별위원회 파일 | 24개 |
| 페이지 | 428페이지 |
| 텍스트 없는 페이지 | 0페이지 |
| 의원-위원회 행 | 9,285개 |
| 일별 상태 | 23,836개 |
| 의원코드 연결 | 9,285행 전체, 고유 320명 |
| 일별 상태와 합계 불일치 | 4행 |

상태별 기록은 출석 20,984, 결석 1,429, 청가 1,086, 출장 295, 결석신고서 42다. 모든 후보 행을 텍스트로 읽고 제22대 재임 이력의 한글명·한자명으로 연결했다.

### 원자료 불일치 4행

| 월·위원회 | 의원 | 일별 상태 | 공개 합계 |
| --- | --- | --- | --- |
| 2026-07 법제사법위원회 | 윤상현 | 출석 4, 결석 3 | 출석 3, 결석 4 |
| 2025-07 국방위원회 | 윤상현 | 출석 1, 청가 1 | 출석 1, 결석 1 |

| 2024-10 외교통일위원회 | 이재명 | 출석 2 | 출석 1, 청가 1 |

이는 PDF 텍스트 추출 오류가 아니라 같은 행에 표시된 일별 상태와 합계의 모순이다. 원문 파일만으로 어느 쪽이 실제 출결인지 확정할 수 없다. 해당 4행은 검토 상태로 남기고, 평가 계산에 넣을 때 일별 회의록 등 별도 근거가 필요하다.

## 3. 파일이 없는 월

파일 목록에는 상임위 2026-06, 특위 2024-06·2025-10이 없다. 위원회 일정 API 1,870행을 교차 확인했다.

| 월 | 일정 API | 실제 성격 | 공개 파일 판단 |
| --- | ---: | --- | --- |
| 2024-06 | 전체회의 29개 포함 32개 | 이름상 상임위 | 특위 파일이 없어도 충돌 없음 |
| 2025-10 | 전체회의 51개 포함 52개 | 이름상 상임위 | 특위 파일이 없어도 충돌 없음 |
| 2026-06 | 전체회의 8개 | 제목상 인사청문·국정조사·기후위기 특위 | 상임위 파일이 없어도 충돌 없음 |

일정 API의 `COMMITTEE_NAME`이 특위를 소관 상임위처럼 표현하는 사례가 있어 `TITLE`을 함께 판단했다. 이 비교에서는 **빈 월이 실제 출결 누락이라는 증거는 발견하지 못했다.** 다만 개별 월 PDF에 특정 위원회가 빠졌는지는 회의별 구조화 후 확인해야 한다.

## 4. 표결 예외 77건의 공식 회의록 확인

[2차 검증](vote-and-identity-audit-2026-10-01.md)의 보류 77건을 회의록과 출결 기록으로 추가 확인했다.

| 날짜·안건 | 공식 근거 | 처리 제안 |
| --- | --- | --- |
| 2024-12-12, 2건 | 제419회 제2차 회의록이 개의 후 조국 의원 퇴직을 보고 | 조국을 분모에서 제외 |
| 2025-07-23, 21건 | 임광현은 7월 22일 궐원. 이주희는 회의록 출석·투표 명단에 없고 제427회 출결도 `-` | 이주희를 분모에서 제외 |
| 2026-03-12, 53건 | 제433회 제1차 회의록이 개의 후 양문석 의원 판결 확정을 보고 | 양문석을 분모에서 제외 |
| 의안 2215128, 1건 | 의장 구두 총계 195/2, 회의록 최종 명단 196/1 및 정춘생 기권→찬성 정정 | 개인 최종 명단 196/1 우선, 총계 불일치 공개 |

이 처리로 77건의 규칙은 정할 수 있다. 전체 데이터셋 생성 시 1,847건 모두에 다시 적용하여 **의안별 재적수·참여자 수·개인 결과·중복 여부가 일치하는지 회귀 검증**해야 한다.

## 5. 현재 평가 가능성

### 본회의 출석

공식 일별 상태, 날짜 완전성, 의원 신원 연결이 확인됐다. 원자료 누적 합계 대신 일별 상태를 쓰면 지표 계산이 가능하다.

### 표결 참여

API 누락을 공식 원문으로 보완할 수 있고 예외 처리 규칙도 마련됐다. 회귀 검증 후 지표 계산이 가능하다.

### 위원회 출석

행과 의원코드 연결은 완료됐지만, 각 PDF의 표 구획·위원회명·날짜 열을 완전히 구조화하고 위원회 재임 이력과 교차해야 한다. **아직 종합등급에 넣지 않는다.**

따라서 다음 시뮬레이션은 입법 성과·본회의 표결 참여·본회의 출석을 먼저 사용하고, 위원회 출석은 별도 항목으로 검증하는 방안을 권고한다. 최종 가중치는 별도 단계에서 결정한다.
