# 데이터 확보 및 검증 계획

기준일: 2026-10-01

**후속 실조회 결과:** [1차 검증 보고서](data-validation-2026-10-01.md). 아래 초기 계획에 미확인으로 적힌 항목의 최신 상태는 이 보고서를 따른다. 개인 표결 API, 출결 파일, 재임 이력의 제공을 확인했으며 표결 누락 보완과 전체 품질 검증은 진행 중이다.

## 1. 주 데이터 소스

[2차 표결·재임 검증 보고서](vote-and-identity-audit-2026-10-01.md)에서 개인 표결 목록 전체 1,847건과 추가 원문 814건을 대조했다. 총계와 신원 검사 통과 1,770건, 재임 경계일·총계 차이로 보류했던 77건은 회의록을 통해 처리 방향을 정했으며 전체 데이터셋 회귀 검증이 남았다. 전체 국회 표결 이벤트 포함 여부는 별도 확인 대상이다.

[3차 출결 검증 보고서](attendance-audit-2026-10-01.md)에서 제22대 공개 본회의 파일 23개와 위원회 파일 50개를 검사했다. 본회의 119일의 일별 상태와 위원회 PDF 9,285행을 제22대 의원코드에 연결했다. 원자료 합계 불일치 5행과 위원회별 회의일 연결은 추가 검증 중이다.

[출결·표결 예외 후속 검증](attendance-followup-2026-10-01.md)에서 본회의 119일과 회의록 날짜 집합이 일치함을 확인하고, 표결 보류 77건의 처리 근거를 회의록에서 확인했다. 위원회 출결의 표 구획·회의일 연결과 원자료 불일치 4행은 계속 검토한다.

- [열린국회정보 Open API](https://open.assembly.go.kr/portal/openapi/main.do)
- [공공데이터포털 국회의원 정보 통합 API 안내](https://www.data.go.kr/data/15126133/openapi.do)

공공데이터포털에 있는 LINK형 서비스는 원 제공기관으로 연결될 수 있으므로 별도 데이터나 별도 인증키가 반드시 필요한 것으로 간주하지 않는다. 개별 서비스의 이용조건·출처표시·호출 제한은 공식 명세로 확인한다.

## 2. 대화 중 확인된 연결 상태

인증키를 사용한 현역의원 API 소규모 조회에서 다음을 확인했다.

- 1페이지와 2페이지가 각각 6건을 반환
- 양쪽 응답 코드 `INFO-000`
- 두 페이지의 의원 식별자가 서로 다름
- 응답의 전체 건수는 당시 299건

이는 인증 및 페이지 이동 확인이며, 전체 수집·개별 기록 검증이 완료됐다는 뜻은 아니다. 키 값과 키가 포함된 요청 URL은 저장하지 않는다.

이전 무인증 조회에서는 5건 제한 및 페이지 고정이 관찰됐다. API 전체 목록 280개를 수집했다고 했던 시도는 같은 5개가 반복된 결과였으므로 전체 목록 확보로 인정하지 않는다.

## 4. 데이터 검증 절차

1. 인증된 서비스 목록과 공식 명세에서 필요한 서비스·필드·지원 대수를 확인한다.
2. 소규모 표본을 읽어 식별자, 상태 코드, 날짜, 재임 이력 연결을 검증한다.
3. 페이지별 식별자 중복, 전체 건수, 결측을 확인해 수집 완전성을 점검한다.
4. 의원별 집계 표본을 국회 원문과 대조한다. 성과가 많은 사례, 0인 사례, 대안반영폐기·중도 입성 사례를 포함한다.
5. 검증된 지표와 계산 불가능한 지표를 구분한 보고서를 작성한다.
6. 평가 기준 합의 이후 전체 수집·집계 구현 단계로 진행한다.

모든 집계에는 조회 시점, 원천 기준일, 평가 기간, 원문 주소, 정정 이력 등 재현에 필요한 정보를 남기는 방향으로 설계한다. 원천 자료가 변경될 수 있으므로 현재 재조회와 과거 성적표를 구분한다.

## 5. 인증정보 운영 원칙

- 실제 인증키는 Git 추적 대상에 두지 않는다.
- 요청 URL, 오류, 디버그 로그에 인증키를 출력하지 않는다.
- 공개 프런트엔드에 키를 포함하지 않는다.
- 로컬 환경변수 및 배포 비밀값 저장소의 구체적 설정은 개발 단계에서 정한다.
